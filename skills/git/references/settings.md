# 利用先の設定と保存先

設定は Plugin ではなく、操作対象の checkout のルートを基準に読む。既存の同等の指定があればそれを優先し、新形式への移行を必須にしない。

## 標準ファイル

| パス | 内容 | Git 管理 |
| --- | --- | --- |
| `.hq/v2/git.md` | 検証の適用条件・コマンド、PR 省略条件など | する |
| `.hq/v2/settings.json` | リポジトリ共通の既定値 | する |
| `.hq/v2/.ignore/settings.json` | checkout／worktree 固有の上書きと作業ブランチの取り込み先 | しない |

`.ignore` は Git の特別なディレクトリ名ではない。ローカル設定を作成する場合は `.gitignore` などで除外されることを確認する。設定には認証情報を保存しない。

worktree の作成方針・配置・保持方針は `AGENTS.md` または参照先の規約に記載する。JSON に同じ運用ルールを重複して追加せず、未指定項目には [worktree の標準運用](worktree.md) を使う。

## 設定項目と優先順位

JSON のルートは object とし、他の Skill の設定があっても保持する。Git 用の項目は `git` の下に置く。コミット前チェックの採用宣言 `commitSecurity` は [導入手順](../../../docs/references/commit-security.md#採用を宣言する)、作業記録・Gotchas・sdd の文書の保存先 `wip.path`・`gotchas.path`・`sdd.path` と、SSOT の登録 `ssot.paths` は [README](../../../README.md#保存先の設定) に従う。

- `remote`: 取り込み先リポジトリの remote 名。例: `origin`。
- `baseBranch`: 新規作業の既定ベース。例: `develop`。
- `branches`: 作業ブランチ名をキーとし、その作業の `{ "remote": "origin", "baseBranch": "develop_xxx" }` を記録する object。値は両項目を含む一組として扱う。

`git.remote` と `git.baseBranch` はそれぞれローカル設定の指定を共有設定より優先する。`branches` はキーごとに重ね、同じ作業ブランチの記録はローカル設定を優先する。文字列は空でないことを確認し、形式が不正なら黙って既定値に戻さず問題を伝える。未指定の値は指示や既存の規約で確定し、`main`・`origin` を暗黙の既定値にしない。

新規作業の既定ベースと、進行中の作業の取り込み先は別に扱う。新規作業ではベースを確定した後、作業ブランチに対応する `branches` の記録をローカル設定へ残す。明示的に共有したい作業の指定は、共有設定へ記載してよい。ローカル設定を新設するときは必要な項目だけを追加し、既存の設定を上書きしない。

再開では作業ブランチの記録と既存 PR の取り込み先を確認する。どちらかだけで確定できるならそれを使い、両者が矛盾する場合は確認する。新規作業用の `baseBranch` が変更されても、既存作業の記録を置き換えない。作業の記録も PR もなければ、既定値を手がかりに取り込み先を確認してから記録する。push 先の追跡ブランチを PR の取り込み先とみなさない。

worktree の作成時には、分岐元で確定した取り込み先を作成先のローカル設定に記録する。未追跡のローカル設定が自動で引き継がれるとはみなさない。ローカル設定が別環境にない場合は、PR や作業記録などから取り込み先を確認する。

## 検証指示との分担

検証コマンドや PR 省略条件は `.hq/v2/git.md` または既存の開発文書に置く。共有する規約をローカル設定で緩めない。スクリプトや CI が検証を定義していれば、文書からそれを参照し、処理内容を複製しない。

利用先向けの [規約例](../../../examples/project/.hq/v2/git.md)、[共有設定例](../../../examples/project/.hq/v2/settings.json)、[ローカル設定例](../../../examples/project/.hq/v2/settings.local.example.json) を、実際のリポジトリに合わせて統合する。参照例の存在や Skill の実行だけで、利用先の設定を一律に新設しない。
