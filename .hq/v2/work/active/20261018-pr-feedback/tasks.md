# pr-feedback の計画と現在地

状態: 実装・自動検証済み、PR 作成中（導入検証は今回の完了条件外）

概要: AI Reviewer の FB の待機・分類・修正・返信・Resolve・再確認を、利用先のオプトインで最大3回実行する。初版から Codex・Claude Code を対象とし、セッション終了後の常駐監視は含めない。

- [設計](design.md)

## 合意の記録

2026-10-18、ユーザーは名称を `pr-feedback` として計画を進めるよう依頼した。追加の質問に対し、次を選択した。

- 監視は「セッションを開いている間だけ」。
- 初版の自動起動は「Codex・Claude Code の両方」。
- Cap は「判断・対応を最大3回」。3回目の修正後もレビュー確認を行い、残る指摘は修正せず報告する。

設計提示後、2026-10-18 のユーザーの「このリポジトリにも同じ仕組みを導入して検証したい」「すすめてくれる？」を実装の続行指示として扱う。その後、ユーザーはこのリポジトリに AI Reviewer がいないため設定不要と訂正し、実際の導入検証は別リポジトリで行うと指定した。実装は継続し、このリポジトリのオプトイン設定と実レビュー検証は行わない。

2026-10-18、ユーザーは利用先セットアップを README に製品別に明記し、別リポジトリでの導入検証を今回の PR の対応条件から除外したうえで PR を作成するよう指示した。今回の PR は通常のレビュー可能な PR とし、実機検証の未実施は結果の制約として記載する。
