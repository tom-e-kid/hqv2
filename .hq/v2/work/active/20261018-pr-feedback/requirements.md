# PR フィードバック対応の要求

状態: 今回の PR の実装・自動検証条件を充足（導入検証は後続作業）

## 目的・範囲

PR 作成・修正後に AI Reviewer が投稿するフィードバック（FB）の確認依頼を繰り返す負担を減らす。利用先リポジトリが明示的に有効化した場合に、待機、トリアージ、必要な修正、検証、コミット・push、理由付き返信、適切な Resolve、再確認、結果報告を行う。

Skill 名は `pr-feedback`。既存 PR に対する手動実行・中断後の再開も提供する。既存の `pr` は PR 作成・更新を担当し、相互の Skill 呼び出しは必須にしない。

## 大枠との関係

- [AGENTS.md](../../../../../AGENTS.md): 共通 Skill と製品固有機能を分離し、要求・設計の合意後に実装する。
- [検証手順](../../../../../docs/validation.md): 構造・参照・配布設定と対象製品での検証を行う。
- [Git 規約](../../../git.md): 作業ブランチから develop へ PR で取り込む。

## 確認済みの要求・判断

2026-10-18 のユーザーの依頼・回答を根拠とする。

- 利用先リポジトリごとのオプトインとし、複数の AI Reviewer に対応する。
- FB が集まるまで待ち、変化がない間はモデルを呼ばない方法を採る。
- 「この PR で対応」「別 PR で検討」「対応不要」に分類し、理由付きで返信する。判断できない内容を無理に分類・解決しない。
- 必要な修正を検証してコミット・push し、解決と判断できるレビューのスレッドを Resolve する。
- 判断・対応の処理を最大3回とする。3回目の修正後も追加レビューを確認し、残る指摘は修正せず報告する。
- 新しい対応対象がなくなった場合、または Cap 到達時に終了して結果を報告する。
- 別 PR 候補は Issue 化するか人間に確認する。
- Cap で収束しなかった場合は、原因を分析して作業メモに残す。
- 初版の監視はセッションを開いている間だけとする。セッション終了後の常駐監視・自動起動基盤は含めない。
- 初版から Codex・Claude Code の両方で自動起動を対象とする。

## 今回の PR の受け入れ条件

| 条件 | 確認方法 |
| --- | --- |
| 未設定・無効なリポジトリでは監視・変更・投稿をしない | 設定・Hook の正常系と無効系のテスト |
| 設定したレビュアーの通常コメント、レビュー本文、レビューのスレッドを取得する | 複数レビュアー・ページ分割を含む取得試験 |
| 複数の FB をまとめ、待機中はモデルを呼ばない | 時刻・API を差し替えた待機試験 |
| コメント0件をレビュー完了と取り違えない | 遅延、完了通知なし、期限切れ、API 失敗の試験 |
| 分類と理由、修正・検証結果を各指摘に返す | 共通 Skill の記述・API を差し替えた投稿試験 |
| push 失敗や検証失敗を修正済みと返信・Resolve しない | 各段階の失敗試験 |
| 通常コメントと Resolve 可能なスレッドを区別する | 返信・Resolve の対象確認 |
| 最大3回を維持し、3回目の修正後にも確認する | 修正あり・なし、再開、上限到達の状態遷移試験 |
| 中断・再入・投稿結果不明でも二重処理や上限リセットを避ける | ロック・永続状態・照合の試験 |
| 人間の FB や外部の head 更新を勝手に処理しない | 対象者判定・競合時の停止試験 |
| Issue 候補と未収束の分析を残す | 終了報告・作業メモのケース確認 |
| 両製品のセットアップを README から進められる | 共通設定・製品別の読み込み・信頼確認・開始・停止の手順を文書と実装で照合 |

## 実装方針・制約

- 待機間隔30→60→120秒、新着後の静穏時間120秒、各 head の待機上限10分を初期案とする。設定可能にし、実機検証で調整する。
- レビュー完了が確認できない場合は「待機期限終了」と報告し、収束と断定しない。
- 別 PR とする妥当性を説明しても、引き継ぎ先未確定・人間の判断待ちのスレッドは自動 Resolve しない。
- 利用先の有効化手順で、修正・commit/push・返信・Resolve の実行範囲を明示する。リポジトリ設定だけでホスト側の権限や承認を迂回しない。
- 既存セッション内の PR 作成を初版の自動起動範囲とする。ブラウザや別プロセスで作られた PR の即時検知は保証せず、手動指定で開始できるようにする。
- 対象レビュアーの識別と完了検出は設定可能にする。初版の動作確認には Copilot と自前レビュアー相当の試験データを含める。

2026-10-18、設計提示後のユーザーの続行依頼に基づいて実装する。その後、ユーザーはこのリポジトリには AI Reviewer がいないため設定不要と訂正し、実際の導入検証は別リポジトリで行うと指定した。このリポジトリのオプトイン設定・レビュー用 PR は追加せず、実機での導入検証は未実施として引き継ぐ。
