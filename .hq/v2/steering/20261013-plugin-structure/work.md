# Plugin の構成と配布名の見直し

着手日: 2026-10-13（Asia/Tokyo）
状態: 反映済み

## 要求と合意

ユーザーの依頼により、Skill だけでなく Claude Code の agent なども収録できる Plugin として、タイトルと構成・開発ルールを見直す。既存の HQ を引き継ぎ、プラグイン名は `hq`、第2世代の開始バージョンは `2.0.0` とする。この依頼を本変更の合意の根拠とする。

## 設計と変更

- 共通の開発ルールは `AGENTS.md` に置き、`CLAUDE.md` はインポートする。タイトルは「HQ Plugin の開発・保守」。目的・構成と責務・変更方針・検証に分ける。
- 共通 Skill は `skills/`、Claude Code の agent はルートの `agents/`。製品固有の機能を追加できるが、共通 Skill はその存在に依存させない。
- agent・Hooks・MCP の配置方針を README に記載する。今回は定義を追加せず、使わない機能の空ディレクトリも作らない。
- 両マニフェストの名前・バージョンを `hq`・`2.0.0` に揃える。両カタログの名前を `hq-marketplace` とし、README と利用先の呼び出し例も更新する。
- 過去の記録は当時の名前・検証結果を保持する。`.hq/v2/steering/` の保存先は変更しない。
