# PR の指示・書式の例

このファイルは任意です。利用する場合は既存の規約へ統合し、利用先の `.hq/v2/pr.md` に置きます。書式を変えない場合は、指示だけを記載しても構いません。

## 指示

- タイトルは Conventional Commits に従う簡潔な一行とする。
- 本文は以下の3見出しを使う。標準書式の見出しを別途追加しない。
- 変更内容は利用者の挙動と結び付け、検証結果には未実施・失敗も明記する。
- 説明文・記入例は完成本文から削除する。

## 本文書式

```markdown
## 目的

<解決する問題と変更後の挙動>

## 対応内容

- <主な変更。必要な場合は互換性や移行への影響も記載>

## 確認結果

- <検証方法・結果・未確認範囲>
```
